# Data sources (downloaded 2026-11-18)

- **Kalshi trade API v2** (public market data, no key): `https://api.elections.kalshi.com/trade-api/v2` — `/markets`, `/historical/markets`, `/events`,
  `/markets/candlesticks`, `/historical/markets/{ticker}/candlesticks`.
- **Polymarket Gamma API** (public): `https://gamma-api.polymarket.com` — `/events/keyset` by league series, `/public-search`, `/teams`.
- **Polymarket Data API** (public): `https://data-api.polymarket.com/v2/prices-history` (3-hour buckets, kept since 2022).
- Window: Kalshi markets that closed 2025-01-01 to 2026-10-31. Descriptive research only; no trading.
